2026-08-10P/N 정리와 자산관리 개선 작업 착수

자산대장의 숨김 열과 불필요한 P/N 정보를 정리하고 웹 화면과 저장 로직에서도 P/N이 다시 입력되지 않도록 조치했습니다.

  • 문제사업장별 자산 시트에 불필요한 P/N 정보와 숨김 열이 남아 있었고, 화면에서 P/N을 계속 입력할 수 있었습니다.
  • 개선자산 관련 5개 시트의 숨김 열을 모두 펼치고 P/N 헤더와 기존 입력값 9개를 삭제했습니다. 데이터 구조를 보존하기 위해 기존 열 위치는 빈 열로 유지했습니다.
  • 개선웹 화면의 P/N 입력란과 저장 로직을 제거하고 정리 전 백업을 만든 뒤 배포 버전 78에 반영했습니다.
  • 검증읽기 전용 재확인에서 5개 시트 모두 숨김 열 0개와 P/N 잔여값 0개를 확인했고, 로컬 자동검사 10종과 등록자·관리자 화면 확인을 통과했습니다.
  • 결과P/N 정리는 완료됐습니다. 지점별 관리자 자동설정, 자산명 검색, 기존 사진 수정, 관리요청 개편과 뒤로가기 세션 복구는 당일 추가 작업 중이며 완료로 표시하지 않습니다.
