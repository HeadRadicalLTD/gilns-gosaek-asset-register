# 고색 자산등록 체크시트

## 등록자 확인

- [ ] 작성자 이름을 입력했다.
- [ ] 품목을 입력했다.
- [ ] 모델명 또는 제작사를 확인했다.
- [ ] 구입처를 입력했다.
- [ ] 금액을 원 단위로 입력했다.
- [ ] 구입일자를 확인했다.
- [ ] 관리자 정보를 확인했다.
- [ ] P/N이 있으면 입력했다.
- [ ] 보관 장소를 확인했다.
- [ ] PC 화면에서 휴대폰 연결 QR을 만들었다.
- [ ] 휴대폰 촬영 화면이 PC와 연결되었다.
- [ ] 송장 사진을 선택했다.
- [ ] 발주서가 있으면 사진을 선택했다.
- [ ] 세금계산서가 있으면 사진을 선택했다.
- [ ] 실물 사진을 선택했다.
- [ ] 사진이 흐리거나 잘리지 않았는지 확인했다.
- [ ] PC 화면의 휴대폰 촬영 수를 확인했다.
- [ ] 등록 완료 관리번호를 확인했다.

## 관리자 검증

- [ ] 관리번호가 중복되지 않았다.
- [ ] 폴더명이 관리번호_구입처_품목 형식이다.
- [ ] 기존 비품 사진 하위 폴더가 유지되어 있다.
- [ ] 송장 폴더가 생성되었다.
- [ ] 발주서 폴더가 생성되었다.
- [ ] 세금계산서 폴더가 생성되었다.
- [ ] 실물 사진 폴더가 생성되었다.
- [ ] 사진이 올바른 폴더에 저장되었다.
- [ ] 고색연구소 시트에 한 행이 추가되었다.
- [ ] 작성자와 등록 일시가 등록이력에 기록되었다.
- [ ] 사진 폴더 링크가 정상적으로 열린다.

## 월간 운영 확인

- [ ] Google Drive 잔여 용량을 확인했다.
- [ ] 접근 권한 변경 여부를 확인했다.
- [ ] 중복 관리번호가 없는지 확인했다.
- [ ] 빈 사진 폴더가 있는지 확인했다.
- [ ] 등록이력과 자산대장 건수를 비교했다.
- [ ] 오류 신고 내역을 확인했다.
