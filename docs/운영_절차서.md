# 고색 자산등록 시스템 운영 절차서

## 1. 목적

고색연구소에서 구매한 자산의 정보와 증빙 사진을
등록자가 직접 입력하도록 하여,
자산대장과 사진 폴더를 같은 기준으로 관리합니다.

## 2. 적용 범위

이 절차는 신규 구매 자산 등록에만 적용합니다.

다음 항목은 현재 범위에서 제외합니다.

- 변경관리
- 정기점검
- 반출관리
- 폐기관리
- OCR 자동인식
- 사용자 계정 인증

## 3. 저장 원칙

- 기존 엑셀 원본은 보존합니다.
- 기존 `비품 사진` 하위 폴더는 변경하지 않습니다.
- 신규 등록 건에 대해서만 폴더를 생성합니다.
- 폴더명은 `관리번호_구입처_품목`을 사용합니다.
- 작성자는 등록 화면에서 직접 입력합니다.
- 등록 일시는 서버 시간으로 자동 기록합니다.

## 4. 등록 절차

1. 배포된 자산등록 URL에 접속합니다.
2. 작성자와 자산 기본정보를 입력합니다.
3. PC에서 `휴대폰 연결 QR 만들기`를 누릅니다.
4. 휴대폰 카메라로 QR을 찍어 연결합니다.
5. 휴대폰에서 사진 종류를 선택해 촬영합니다.
6. PC 화면에 표시된 촬영 사진 수를 확인합니다.
7. 필요한 PC 저장 사진이 있으면 추가합니다.
8. 입력 내용과 선택 사진 수를 확인합니다.
9. `자산 등록하기`를 누릅니다.
10. 관리번호와 사진 폴더 링크를 확인합니다.
11. 오류가 표시되면 다시 등록하지 말고
   관리자에게 화면 내용을 전달합니다.

## 5. 자동 처리 절차

등록 요청이 들어오면 시스템은 다음 순서로 처리합니다.

1. 필수 입력값과 이미지 파일을 검사합니다.
2. 다른 등록 작업과 번호가 겹치지 않게 잠급니다.
3. 고색연구소 시트의 다음 관리번호를 계산합니다.
4. 새 자산 폴더와 네 개의 하위 폴더를 만듭니다.
5. PC와 휴대폰 사진을 종류별 폴더에 저장합니다.
6. 고색연구소 시트에 자산정보를 입력합니다.
7. 등록이력 시트에 작성자와 폴더 링크를 남깁니다.
8. 휴대폰 임시 촬영 폴더를 정리합니다.
9. 완료 결과를 등록자에게 표시합니다.

## 6. 오류 처리

- 사진 저장 중 오류가 나면 새 폴더를 휴지통으로 이동합니다.
- 휴대폰 연결은 생성 후 4시간 동안 유지됩니다.
- 연결이 만료되면 PC에서 새 QR을 생성합니다.
- 자산대장에는 완료된 등록만 기록합니다.
- 같은 등록 버튼을 여러 번 누르지 않습니다.
- 관리번호가 중복되면 등록을 중단하고 관리자에게 알립니다.

## 7. 관리자 확인

관리자는 정기적으로 다음을 확인합니다.

- 웹앱 URL 정상 접속
- Google Drive 저장공간
- 사진 폴더 권한
- 고색연구소 시트 입력 상태
- 등록이력과 사진 폴더 링크 일치
- 실패 등록 또는 휴지통 폴더 존재 여부

## 8. 권한 권고

- 자산관리 폴더는 불특정 다수에게 공개하지 않습니다.
- 웹앱은 링크를 아는 사용자만 접근하게 설정합니다.
- Apps Script는 소유자 권한으로 실행합니다.
- 관리자 외 사용자는 원본 자산대장을 직접 수정하지 않습니다.
